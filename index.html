Integration is the foundation

Agentic AI is an integration problem.

Integration flows run predefined logic. Agents use models to decide their next action at runtime. Both still call systems they do not control, exchange structured data, act on behalf of users, and wait on work that can take hours or days.

Agentic applications do not remove the need for integration principles. They make those principles more important: reliable connectivity, secure interactions, observability, structured data handling, and support for long-running execution.

Ballerina builds these principles into the language, so integrations and agents are written with the same services, clients, types, and error handling.

Ballerina for AI

Build agents that work with enterprise systems.

An enterprise agent needs models, tools, and other agents to work with. Ballerina brings these together with the language constructs and connector ecosystem used to build integrations.

The diagram is a view of the same source, not a separate artifact. Type and client declarations are omitted. Order and Triage are declared types: the compiler checks every use of their fields, and the API and model responses are checked against them at runtime, so a malformed response surfaces as an error.
